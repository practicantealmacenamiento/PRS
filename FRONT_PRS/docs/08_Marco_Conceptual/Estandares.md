# Marco Conceptual

## Estandares de referencia

### ISO/IEC 25010
Modelo de calidad de software que cubre funcionalidad, rendimiento, usabilidad, confiabilidad, seguridad, mantenibilidad y portabilidad. Se utiliza para evaluar la experiencia del frontend y su estabilidad.

### IEEE 830 e IEEE 1063
- **IEEE 830**: guia para especificaciones de requisitos, inspira el formato de requisitos funcionales y no funcionales.
- **IEEE 1063**: buenas practicas para documentacion tecnica y manuales de usuario.

### OWASP ASVS / OWASP Top 10
Lista de riesgos de seguridad aplicables a aplicaciones web. Se recomienda revisar almacenamiento de tokens, proteccion de sesiones y manejo de errores.

### WCAG 2.1
Lineamientos de accesibilidad para asegurar que la interfaz sea usable por distintos perfiles de usuario.

### Guia Scrum
Marco agil utilizado para planificar iteraciones, retrospectivas y releases del frontend.

La combinacion de estos estandares proporciona un marco consistente para mantener calidad, seguridad y documentacion en el frontend RadioFrecuencias.
